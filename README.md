# 튼튼몬 키우기

운동하고 골고루 먹으면 자라고, 안 돌보면 시드는 건강 습관 육성 게임입니다. (DEOK TT)

## 실행
- `index.html`을 브라우저로 열면 바로 됩니다. 빌드 과정이 없습니다.
- 기획과 규칙은 [`CLAUDE.md`](CLAUDE.md)에 있습니다.

## 배포 (GitHub + Vercel)
1. 이 폴더를 GitHub 새 저장소에 올립니다.
2. vercel.com → Add New → Project → 그 저장소 Import
3. Framework Preset: **Other**, Build Command: 비움, Output Directory: 비움 → Deploy
4. 이후 main에 올릴 때마다 자동 배포됩니다.
